# Repository contents

| Folder | What it is |
| ------ | ---------- |
| [`warehouse-twin/`](warehouse-twin/) | Interactive 3D light digital twin of the Phuoc An Port warehouse F1 / F2 project (Vite + Three.js). See its README for how to run, build and edit `config.js`. |

Quick start:

```bash
cd warehouse-twin
npm install
npm run dev
```

A ready-to-open single-file version is in `warehouse-twin/release/phuoc-an-warehouse-twin.html`.
